3️⃣ Database Schema (Supabase)

Users Table

Column	Type	Description

user_id	integer PK	Telegram user ID
country	text	Selected country
category	text	Interest category
join_date	timestamp	Registration date
active	boolean	Active status
blocked	boolean	Blocked by admin


Broadcasts Table

Column	Type	Description

broadcast_id	integer PK	Unique ID
user_id	integer FK	Creator (if user broadcast)
text	text	Broadcast message
media_url	text	Optional media link
target_country	text	Target country / NULL = all
target_category	text	Target category / NULL = all
price	numeric	Price per broadcast
ads_required	boolean	Whether ads are required
monetag_ads	json	Ads details (SDK)
status	text	pending / approved / sent
created_at	timestamp	Creation time
sent_at	timestamp	Send time


Analytics Table

Column	Type	Description

id	integer PK	Unique ID
broadcast_id	integer FK	Linked broadcast
user_id	integer FK	Recipient user ID
viewed	boolean	If message viewed
reaction	text	Reaction emoji / poll answer
timestamp	timestamp	Interaction time


Payment Table

Column	Type	Description

payment_id	integer PK	Unique ID
user_id	integer FK	User who paid
broadcast_id	integer FK	Broadcast linked
amount	numeric	Paid amount
gateway	text	Payment method (Stars / Crypto)
status	text	completed / pending / failed
timestamp	timestamp	Payment time


Admin Logs Table

Column	Type	Description

log_id	integer PK	Unique ID
admin_id	integer	Admin Telegram ID
action	text	Action type
broadcast_id	integer FK	Optional broadcast reference
timestamp	timestamp	Action time

4️⃣ Workflow Example

1. User Registers → select country + category → saved in DB


2. User Creates Broadcast → sets message, media, target, price, ads


3. Payment Required? → User pays via integrated gateway → status updated in DB


4. Admin Panel → sees pending broadcasts, analytics, payments, can edit/remove ads, change price


5. Bot Delivery → sends approved broadcasts to selected users


6. Analytics Updated → views, reactions, clicks, engagement logged


7. Admin Dashboard → full control: block users, view activity, adjust prices

5️⃣ Tech Stack Recommendation

Bot: Python pyTelegramBotAPI

Web App: Flask (backend) + React (frontend optional) → Render free tier

Database: Supabase free tier → users, broadcasts, payments, analytics

Payment Gateways: Stars, Telegram wallet, X Rocket, CryptoPay

Monetag Ads: SDK integrated in web app → controlled per broadcast by admin

Hosting: Render free tier → Flask + React + background bot process
